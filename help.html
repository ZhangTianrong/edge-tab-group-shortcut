This extension only works on Windows and requires a separate native companion install.

Finish The Windows Setup

TabGroup Keyboard Shortcuts can only detect hovered tab groups after the native companion is installed. The extension by itself is not enough.

Windows only Native companion required AutoHotkey optional

Install Summary

  1. Download the Windows companion package from the project release or repository.
  2. Run install.ps1 from PowerShell.
  3. Reload the extension in Edge after the installer finishes.
  4. Optional: run the AutoHotkey helper if you want middle-click tab-group closing.

Keyboard Shortcuts

  • Alt+Shift+W: close all tabs in the hovered group
  • Alt+Shift+Q: close all other tab groups

Full Instructions

Follow the Windows setup guide on GitHub: docs/WINDOWS_SETUP.md

Detector Configuration

  • TABGROUP_HOVER_EXTRA_COLORS: extra tab-group colors to accept, like #5E87BC,#DB6ABA.
  • TABGROUP_HOVER_BG_COLORS: background colors used to split groups, like #000000,#333333.
  • TABGROUP_HOVER_MIN_GROUP_WIDTH: minimum colored segment width in pixels. Default: 24.
  • TABGROUP_HOVER_MIN_BG_GAP_WIDTH: minimum background gap width in pixels between groups. Default: 8.
  • TABGROUP_HOVER_DETECTOR_VERBOSE: enables detector logs and diagnostic screenshots.

Common Problems

  • If the shortcuts do nothing, the native host is usually missing or registered to the wrong extension ID.
  • If you are testing the unpacked extension, use the development install flow from the GitHub guide.
  • If hover detection is inaccurate, enable the detector’s verbose mode from the guide and review the generated diagnostics.
